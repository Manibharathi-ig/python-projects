# 🗺️ Text Adventure Game

A simple command-line adventure game built using Python. The player makes choices throughout the story, and each decision leads to a different outcome. The objective is to make the correct choices to successfully complete the adventure.

##  Features

- Interactive story-based gameplay
- Multiple decision paths
- Different game endings
- Personalized experience using the player's name
- Input validation for user choices

##  Technologies Used

- Python 3

##  Concepts Practiced

- Variables
- User Input (`input()`)
- Conditional Statements (`if`, `elif`, `else`)
- Nested Conditional Statements
- String Methods (`lower()`)
- Program Flow Control

##  How to Run

1. Clone this repository.
2. Open the project folder.
3. Run the following command:

```bash
python main.py
```
