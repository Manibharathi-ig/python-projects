#  Number Guessing Game

A simple command-line Python game where the computer generates a random number within a user-defined range. The player must guess the correct number, and the program provides hints until the correct answer is found.

##  Features

- User-defined number range
- Random number generation
- Input validation
- Hint messages (Too High / Too Low)
- Guess counter
- Displays the total number of attempts

##  Technologies Used

- Python 3
- Random Module

##  Concepts Practiced

- Variables
- User Input (`input()`)
- Conditional Statements (`if`, `elif`, `else`)
- While Loops
- `break` and `continue`
- Type Conversion
- Input Validation (`isdigit()`)
- Random Number Generation (`random.randint()`)

## ▶ How to Run

1. Clone this repository.
2. Open the project folder.
3. Run the following command:

```bash
python main.py
```
