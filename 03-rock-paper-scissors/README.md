#  Rock Paper Scissors Game

A simple command-line Rock Paper Scissors game built using Python. The player competes against the computer, which randomly selects Rock, Paper, or Scissors. The game continues until the player chooses to quit, while keeping track of the scores.

##  Features

- Play against the computer
- Random computer choices
- Input validation
- Score tracking
- Continuous gameplay until the user quits
- Displays the final scores

##  Technologies Used

- Python 3
- Random Module

##  Concepts Practiced

- Variables
- Lists
- User Input (`input()`)
- Conditional Statements (`if`, `elif`, `else`)
- While Loops
- Random Number Generation (`random.randint()`)
- Score Tracking
- Program Flow Control

## ▶ How to Run

1. Clone this repository.
2. Open the project folder.
3. Run the following command:

```bash
python main.py
```
